Write a function that returns the missing number in a list containing n distinct integers from 1 to n+1
skill: 4
Description
Use O(n) time

def find_missing(nums):
    n = len(nums) + 1
    expected = n * (n + 1) // 2
    actual = 0
    for num in nums:
        actual += num
    return expected - actual

Question 5:
Create a function that sorts through an unordered list.
skill: 11
Description



def sorter(x):
    n = len(x)
    for y in range(n):
        s = False
        for w in range(0, n - y - 1):
            if x[w] > x[w + 1]:
                x[w], x[w + 1] = x[w + 1], x[w]
                s = True
        if not s:
            break
    return x

The function f(a, b) where it finds the factorial of a and b and adds them together. Allowed to make two functions.



def f(a, b):
    if b == 0:
        if a == 0 or a == 1:
            return 1
        return a * f(a - 1, 0)
    if a == 0:
        if b == 0 or b == 1:
            return 1
        return b * f(0, b - 1)
    return f(a, 0) + f(0, b)

Write a recursive function remove(string, char) to remove 
char from string.
For instance, remove('hello', 'h') returns 'ello'.


def remove(string, char):
    if string == '':
        return ''
    if string[0] == char:
        return remove(string[1:], char)
    else:
        return string[0] + remove(string[1:], char)
